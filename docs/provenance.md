# Provenance and public records

WatchOver was built entirely through HELM's council, executor and operations workflow.
AI roles handled design, implementation and independent review. A human set the goals,
manually routed messages and approved actions. HELM describes the process; it is not a
runtime dependency. This workflow does not claim automatic inter-agent communication or
unattended governance.

Missing records and capture errors remain identified; publication does not establish
complete transcript coverage or change the experimental limitations below.

## Product and evidence

This edition preserves the provider-independent local recorder, schema, read-only view,
generic skills and useful synthetic fixtures/tests from accepted source version 0.1.2.
Legacy evaluation procedures and placeholder documents are excluded. Its public Git
history starts from the sanitized edition; private source ancestry is not included.

Development used three experimental stages W1-W3 on GCP. W2 had two runs and both formal
arm verdicts were INVALID. The final stage was one Basic-mode observation with unresolved
evidence limits, not a controlled causal proof. These records do not establish current
0.1.2 cloud validation, universal support, AI obedience or measured causal/performance
benefit. [Validation](validation.md) states the local contract and its limitations.

[Agent Run Recorder](https://github.com/helmls-studio/agent-run-recorder) is a separate
related tool. It is not a dependency of WatchOver or a validation result for this edition.
